# Dipali Tayde | Build. Create. Communicate.

A personal portfolio website for **Dipali Tayde**, a BTech student at NXTwave Institute, Pune. It shows her journey, skills, achievements and creative side, with an honest, beginner-friendly tone. It has animated gradients, a custom sunflower cursor and a light/dark theme.

## About the Portfolio

The site tells a story in five moves: **achieve, explore, connect, build, create**. Instead of inflating skills, it labels each one with its real level (*learning*, *building* or *comfortable*). It brings together technology (web development, Python, Generative AI) and creative and communication skills (painting, dance, anchoring, public speaking).

## Sections

| Section | What it covers |
|---|---|
| **Hero** | Name, tagline, portrait and call-to-action buttons |
| **About** | Short bio and a quick-facts list (education, interests, what she is open to) |
| **The short version** | Five-step progression of her story |
| **Journey** | Timeline from Class 12 to the present and next steps |
| **Skills** | Technology, Creative and Communication skills with honest level tags |
| **Beyond code** | Cards on painting, dance, anchoring, content creation and more |
| **Recognition** | 96% in Class 12 (district topper, Burhanpur), meeting the Chief Minister of MP, and prizes in painting, dance and quiz |
| **Learning lab** | What she is currently studying |
| **Interests** | Interactive tabs: Build, Create, Perform, Explore |
| **What makes me, me** | Six personality traits |
| **Contact** | LinkedIn, Instagram and GitHub links |

## Features

- Responsive layout that works on mobile and desktop
- Light and dark theme toggle
- Background gradient that changes as you scroll through sections
- Scroll-reveal animations
- 3D tilt effect on cards and the portrait
- Custom sunflower cursor with a trail and click ripple
- Interactive tabs in the Interests section
- Respects the `prefers-reduced-motion` setting for accessibility
- Google Fonts: **Fraunces** and **Inter**

## Tech Stack

- **HTML5**
- **CSS3** (custom properties, gradients, animations)
- **JavaScript** (vanilla: IntersectionObserver, canvas, pointer events)

No frameworks or build tools are needed.

## Getting Started

### Run locally

1. Clone the repository
   ```bash
   git clone https://github.com/dipalitayde01/my-portfolio.git
   ```
2. Go into the folder
   ```bash
   cd my-portfolio
   ```
3. Open `portfolio.html` in your browser, or use a local server such as the VS Code **Live Server** extension.

### Deploy

You can host it for free with **GitHub Pages**: go to *Settings → Pages*, choose the `main` branch, and save.
